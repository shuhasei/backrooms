# Infinite Backrooms

ブラウザだけで動く、無限生成型の Backrooms 風 3D 空間です。

提供された参考画像の「低い天井」「黄ばんだ蛍光灯」「薄い模様の壁紙」「くすんだカーペット」「柱と中途半端な間仕切り」を観察し、**画像そのものは配布せず**、CanvasTexture と Three.js で質感を手続き生成しています。ウォーターマーク付き素材や第三者の参考画像はリポジトリに含めていません。

## 特徴

- Three.js による一人称 3D 表示
- プレイヤー周囲のチャンクを自動生成・破棄するため、歩き続けられる構成
- 壁紙の細かな縦地＋反復模様をランタイム生成
- くすんだカーペット、天井タイル、巾木、柱、蛍光灯を手続き生成
- ライトの微妙なちらつき、フォグ、粒子ノイズ、軽いビネットで「高解像度化」ではなく写真らしい空気感を重視
- 壁・柱との簡易コリジョン
- 蛍光灯の低いハム音（`M` キーで ON/OFF）
- 外部の画像アセットなし

## 操作

- クリック: マウスロック / 開始
- `W A S D`: 移動
- `Shift`: 走る
- `M`: 蛍光灯のハム音 ON/OFF
- `Esc`: マウスロック解除

## 実行

静的サイトなので、ローカルでは簡易 HTTP サーバーから開いてください。

```bash
python -m http.server 8000
```

その後 `http://localhost:8000` を開きます。

## GitHub Pages

このリポジトリはそのまま GitHub Pages で配信できます。

1. Repository **Settings** → **Pages**
2. **Deploy from a branch** を選択
3. Branch を `main`、folder を `/ (root)` に設定

Three.js は jsDelivr CDN から ES Modules として読み込みます。
